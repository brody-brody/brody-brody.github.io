About the Project

Bee Darts is a 3D puzzle sandbox game demo where you can throw bees like darts to interact with your surroundings. All objects are interactable, and every new object has a unique interaction.

Features

  • Flexible hex grid map with custom Unity editor tools for rapid level creation and expansion
  • Short and sweet gameplay built around unique object interactions and player experimentation
  • Polished movement, shaders, sounds, and game-feel all for good viewing and playing experience

Development Process

Starting out essentially as a joke, Bee Darts was born from a silly brainstorming activity of slapping two random words together. As the project evolved, it grew from simply implementing mechanics to creating a system that made it easy to build new interactions. To support rapid iteration, I designed a hex-grid framework alongside custom editor tools that allowed maps and dartboards to be expanded without manual placement or assignment. Throughout development, I focused mainly on creating reusable systems that made experimenting with silly things fast while still maintaining a polished experience.

What I Learned

  • A much better understanding of editor tools, like the snap-to-grid map tool, or how the map visualizes what hexagons belong to which dartboard
  • My first 'polished' 3D game, which obviously includes movement, first-person camera and sensitivity
  • In-depth into Unity-specific derived classes, as all objects derive from a dartboard base class
  • Working with axial coordinate systems to convert between a hex grid and a square grid
